# QQ空间动态批量获取工具

一个用于批量获取QQ空间好友动态/说说的工具，支持翻页抓取、数据去重、导出JSON/CSV格式，以及原图批量下载。

## 功能特性

### 浏览器用户脚本 (qqzone-fetch.user.js)

- **批量抓取动态** - 自动翻页获取指定好友的所有动态
- **智能配置** - 支持设置最大页数、每页条数、请求间隔
- **内容筛选** - 可选择包含纯图片或视频类型的动态
- **数据去重** - 自动过滤重复内容
- **实时预览** - 内置数据表格展示抓取结果
- **多格式导出** - 支持导出为JSON或CSV格式
- **原图下载** - 内置图片下载功能，自动转换webp为jpg

### Python下载脚本 (download_qzone_images.py)

- **多格式支持** - 解析JSON和CSV两种导出格式
- **智能识别** - 自动提取qpic.cn和photo.store.qq.com域名的图片
- **URL优化** - 将缩略图链接转换为原图链接
- **格式转换** - 自动将webp格式转换为jpg
- **断点续传** - 跳过已存在的文件，支持增量下载
- **批量下载** - 多线程下载，带进度显示

## 安装说明

### 浏览器用户脚本

1. 安装浏览器扩展：
   - [Tampermonkey](https://www.tampermonkey.net/) (推荐)
   - [Greasemonkey](https://www.greasespot.net/)

2. 安装用户脚本：
   - 打开Tampermonkey管理面板
   - 创建新脚本
   - 将 `qqzone-fetch.user.js` 的内容粘贴进去
   - 保存并启用脚本

### Python脚本

1. 确保已安装Python 3.7+

2. 安装依赖：
   ```bash
   pip install requests pillow
   ```

## 使用方法

### 浏览器脚本使用

1. 登录QQ空间 (https://user.qzone.qq.com)
2. 访问好友的空间主页
3. 点击页面右上角的浮动按钮（下载图标）
4. 在弹出的面板中：
   - 输入目标QQ号（通常会自动识别）
   - 配置抓取参数（页数、条数、间隔）
   - 选择筛选条件
   - 点击"开始获取"
5. 等待抓取完成，可以：
   - 查看实时统计和数据表格
   - 导出为JSON或CSV文件
   - 直接下载所有图片

### Python脚本使用

1. 准备导出的数据文件（JSON或CSV格式）

2. 运行下载脚本：
   ```bash
   python download_qzone_images.py <数据文件路径>
   ```

3. 按提示输入保存目录（默认为数据文件同目录下的 `qzone_images` 文件夹）

4. 等待下载完成

## 技术栈

- **前端**: 原生JavaScript + Tampermonkey/Greasemonkey API
- **后端**: Python + requests + Pillow
- **API**: QQ空间内部接口 (`ic2.qzone.qq.com`)

## 配置说明

### 浏览器脚本配置项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 最大页数 | 100 | 最多抓取的页数 |
| 每页条数 | 20 | 每次请求获取的动态数量（最大40） |
| 间隔时间 | 1500ms | 每页请求之间的等待时间 |
| 包含纯图片 | 开启 | 是否包含只有图片没有文字的动态 |
| 包含视频 | 关闭 | 是否包含视频类型的动态 |

### Python脚本特性

- 自动识别图片域名：`qpic.cn`、`photo.store.qq.com`
- URL转换规则：`!/m` 或 `!/c` 或 `!/s` → `!/b`（获取原图）
- Webp转换：自动转换为JPG格式，质量95%
- 文件命名：优先使用URL中的`bo`参数，否则使用随机签名

## 注意事项

1. **登录状态** - 使用前请确保已登录QQ空间
2. **频率限制** - 建议保持默认的请求间隔，避免触发反爬机制
3. **权限要求** - 只能获取你有权限查看的好友动态
4. **存储空间** - 大量图片下载需要足够的磁盘空间
5. **网络环境** - 下载大量图片需要稳定的网络连接

## 常见问题

**Q: 为什么有些动态获取不到？**
A: 可能的原因包括：动态设置了权限、非好友关系、或者动态已被删除。

**Q: 下载的图片质量不好怎么办？**
A: 脚本默认会将缩略图URL转换为原图URL（`!/b`），如果仍然模糊，可能是原图本身质量有限。

**Q: 可以同时获取多个好友的动态吗？**
A: 当前版本需要逐个好友获取，不支持批量多用户模式。

**Q: Python脚本报错怎么办？**
A: 请确保已正确安装依赖（`pip install requests pillow`），并检查数据文件格式是否正确。
